# self-agent

本机优先个人管家原型：日程 + 多账户财务。

## 当前正式原型

完整可跑版在 `www/`：

- `www/index.html` 页面
- `www/styles.css` 样式
- `www/app.js` 账本 / 日程逻辑

浏览器直接打开 `www/index.html` 即可。底栏：首页 / 日程 / 记录 / 财务 / 我的。账户只在财务页内。

仓库根目录还有一套 Sites/日程展示页（`app/page.tsx`），和完整原型不是同一份代码。

## 上传本地文件

GitHub 网页：Add file → Upload files，上传三个文件到 `www/`。
